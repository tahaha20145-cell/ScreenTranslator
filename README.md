# Screen Translator (Android)

แอปแปลข้อความบนหน้าจอเกมเป็นภาษาไทย: ปุ่มกลมลอยทับเกม แตะแล้วอ่านข้อความ (ML Kit OCR) และแปลแบบออฟไลน์ (ML Kit Translate) แสดงคำแปลทับตำแหน่งเดิม

## สร้างไฟล์ APK (ทำครั้งเดียว ไม่ต้องลง Android Studio)
1. สร้าง repository ใหม่บน GitHub (Private ก็ได้)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `.github`)
3. เปิดแท็บ **Actions** -> workflow **Build APK** -> รอ 3-5 นาที
4. เข้าไปที่ run ที่เสร็จแล้ว -> ดาวน์โหลด **ScreenTranslator-APK** (ได้ `app-debug.apk` ใน zip)
5. ส่ง APK เข้ามือถือ แล้วติดตั้ง (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก")

## วิธีใช้
1. เปิดแอป เลือกภาษาในเกม / แปลเป็น แล้วกด **เริ่มใช้งาน**
2. อนุญาต "แสดงทับแอปอื่น" และ "บันทึกหน้าจอ"
3. เปิดเกม -> **โหมดต่อเนื่อง** (ค่าเริ่มต้น): แตะปุ่ม 1 ครั้งเพื่อเริ่มแปลซับไตเติลอัตโนมัติ (ปุ่มเป็นสีเขียว) คำแปลขึ้นที่แถบฝั่งตรงข้ามกับซับ และไม่บังการกดเกม แตะปุ่มอีกครั้งเพื่อหยุด
   **โหมดทีละครั้ง**: แตะปุ่ม = แปลทั้งจอ, แตะที่ใดก็ได้ = ปิดคำแปล
4. กดปุ่มค้าง ~1 วินาที = ปิดโปรแกรม

ครั้งแรกต้องต่อเน็ตเพื่อโหลดโมเดลภาษา (~30 MB ต่อภาษา)
ต้องใช้ Android 8.0 ขึ้นไป
